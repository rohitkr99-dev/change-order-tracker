# Change Order Tracker

Offline-first web app (PWA) for logging construction/engineering change orders and RAID items on site, with a one-page project status report.

- Works offline; data stays on your device (IndexedDB).
- Install from your phone browser: "Add to Home screen" / "Install app".
- CSV export/import and full JSON backup on the Settings tab.
- Not accounting or contractual advice - check amounts against your contract.
